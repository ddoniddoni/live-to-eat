# LiveToEat

**LiveToEat은 사람을 통해 새로운 맛집을 발견하고, 나만의 맛집 지도를 만들며, 원하는 지역의 장소만 골라 공유하는 서비스입니다.**

국내 음식점, 카페, 베이커리처럼 다시 찾고 싶은 장소를 내 지도에 저장합니다. 다른 사람의 공개 지도를 둘러보다 마음에 드는 장소를 발견하면, 그 장소를 내 기록으로 저장할 수도 있습니다. 여행지나 동네처럼 특정 지역의 장소만 선택해 링크로 공유하면, 앱이 없는 사람도 웹에서 볼 수 있습니다.

## 출시할 기능

- 공공데이터 기반 자체 장소 DB에서 검색한 장소를 네이버 지도 위의 내 저장으로 비공개 보관합니다.
- 방문 여부, 개인 메모, 태그, 개인 폴더로 내 기록을 정리합니다.
- 지역별로 다른 사람의 공개 지도를 둘러보고 장소를 내 지도에 저장합니다.
- 국내 지역을 기준으로 장소를 골라, 만료하거나 철회할 수 있는 공유 링크를 만듭니다.
- 받은 공유 링크는 앱 또는 모바일 웹에서 엽니다.

## 지키는 원칙

- 내 지도에는 내 저장만 보입니다. 다른 사람의 저장은 둘러보기와 상대방 지도에서 봅니다.
- 다른 사람의 장소를 저장해도 그 사람의 개인 메모와 방문 기록은 복사하지 않습니다.
- 모든 저장은 기본적으로 비공개입니다. 공개 지도, 링크 한정 공유, 개인 메모를 분리합니다.
- 지역 공유는 링크를 만든 시점에 고른 장소의 스냅샷입니다. 이후 새로 저장한 장소가 자동으로 추가되지 않습니다.
- 비공개 전환, 삭제, 링크 철회는 다음 조회부터 공유 링크에 반영됩니다.
- 첫 출시는 대한민국을 대상으로 합니다. 한국어/영어 UI와 확장 가능한 지역 구조를 유지합니다.

## 현재 상태

LiveToEat은 iOS/Android용 React Native 앱과 공유 링크용 작은 웹 화면의 UI 및 로컬 체험 기능을 구현한 단계입니다. 실제 계정·DB·지도·공유와 스토어 출시는 아직 완료하지 않았습니다.

2026-09-13에 **네이버 Maps + 공공데이터 기반 자체 장소 DB**로 설계를 확정했습니다. 기본 자료는 소상공인시장진흥공단 상가(상권)정보이며, 장소의 출처와 갱신 이력을 사용자 메모·방문 기록과 분리해 관리합니다. 네이버/카카오 검색은 필요할 때 이용 조건을 확인할 보조 후보입니다.

현재 코드는 전환 전이며, 다음 작업은 여러 국내 지역의 장소 데이터 품질과 iOS/Android 네이버 지도 호환성 검증입니다. 이 결과를 바탕으로 SDK, 데이터 적재, 검색·저장 API, 공유 웹을 차례로 전환합니다.

# LiveToEat

**LiveToEat은 사람을 통해 새로운 맛집을 발견하고, 나만의 맛집 지도를 만들며, 원하는 지역의 장소만 골라 공유하는 서비스입니다.**

음식점, 카페, 베이커리처럼 다시 찾고 싶은 장소를 내 지도에 저장합니다. 다른 사람의 공개 지도를 둘러보다 마음에 드는 장소를 발견하면, 그 장소를 내 기록으로 저장할 수도 있습니다. 여행지나 동네처럼 특정 지역의 장소만 선택해 링크로 공유하면, 앱이 없는 사람도 웹에서 볼 수 있습니다.

## 할 수 있는 일

- Google 장소 검색 또는 Google Takeout 파일에서 장소를 가져와 내 지도에 비공개로 저장합니다.
- 방문 여부, 개인 메모, 태그, 개인 폴더로 내 기록을 정리합니다.
- 지역별로 다른 사람의 공개 지도를 둘러보고 장소를 내 지도에 저장합니다.
- 국가와 지역을 기준으로 장소를 골라, 만료하거나 철회할 수 있는 공유 링크를 만듭니다.
- 받은 공유 링크는 앱 또는 모바일 웹에서 엽니다.

## 지키는 원칙

- 내 지도에는 내 저장만 보입니다. 다른 사람의 저장은 둘러보기와 상대방 지도에서 봅니다.
- 다른 사람의 장소를 저장해도 그 사람의 개인 메모와 방문 기록은 복사하지 않습니다.
- 모든 저장은 기본적으로 비공개입니다. 공개 지도, 링크 한정 공유, 개인 메모를 분리합니다.
- 지역 공유는 링크를 만든 시점에 고른 장소의 스냅샷입니다. 이후 새로 저장한 장소가 자동으로 추가되지 않습니다.
- 비공개 전환, 삭제, 링크 철회는 다음 조회부터 공유 링크에 반영됩니다.
- 한국식 지역 구조를 모든 나라에 강제하지 않고, 국가별 지역 체계를 지원합니다.

## 현재 상태

LiveToEat은 iOS/Android용 React Native 앱과 공유 링크용 작은 웹 화면의 기반을 갖춘 초기 구현 단계입니다. 모바일 앱은 개발 빌드에서 실행되며, 실제 지도·장소 검색·로그인·가져오기·공유 기능은 순서대로 구현하고 검증합니다.

Google 저장목록의 첫 일괄 가져오기는 Google 로그인 연동이 아니라 **Google Takeout ZIP/CSV 파일 가져오기**로 제공합니다. 로그인만으로 개인 저장목록을 즉시 읽거나 전 세계에서 자동 동기화된다고 약속하지 않습니다.

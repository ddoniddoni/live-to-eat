# 01. 제품 명세와 사용자 경험

문서 버전 2.0 | 기준일 2026-09-09 | 상태: 초기 구현 중

## 1. 제품 정의

**LiveToEat은 내가 저장한 맛집 지도를 만들고, 다른 사람의 맛집 지도를 구경하며, 필요한 지역만 공유하는 서비스다.**

첫 제품은 iOS/Android 앱이다. 한국 전용 서비스가 아니라 세계의 음식점, 카페, 베이커리와 식음료 장소를 담는다. UI는 한국어/영어로 출시하고 다른 언어를 추가할 수 있게 한다. 실제 스토어 공개 국가는 지역별 검증 후 순차 확대한다. 국제 데이터 구조와 모든 국가에서의 품질/법적 적합성 보장은 다른 문제다.

Google Maps를 사용하는 이유는 국제 장소 탐색과 모바일 지도 경험이다. Google 지도의 개인 저장목록은 지도 SDK와 별개 자원이며, 가져오기 제약은 [03 문서](03_MAPS_AND_IMPORT.md)가 기준이다.

핵심 흐름:

```text
Google 저장목록 가져오기 또는 장소 검색
→ 내 지도에 비공개 저장
→ 다른 사람의 공개 지도 탐색
→ 마음에 드는 곳을 내 지도에 저장
→ 국가/지역 선택
→ 공유할 장소 확인
→ 링크 전송
→ 상대방이 앱 또는 웹에서 열람
```

## 2. 첫 출시 필수 범위

P0는 출시 전 반드시 구현한다. P0-S는 P0를 가능하게 하는 사전 기술 검증이다. P1은 첫 출시가 없어도 되는 기능으로 숨기며 준비 중 버튼으로 화면을 채우지 않는다.

| ID | P0 요구사항 | 완료 조건 |
|---|---|---|
| R01 | 개인 지도와 목록 | 내 저장만 표시하고 앱 종료/재로그인 후 유지한다. 장소 개수와 지도 표시 가능 개수를 구분한다. |
| R02 | 국제 장소 검색 | Google Places로 상호/지역을 검색한다. 국가, 지점, 주소를 확인한 후 저장한다. |
| R03 | 저장 편집 | 삭제, 가고 싶은 곳/방문한 곳, 개인 메모, 태그, 추천 표시가 동작한다. |
| R04 | 사람 중심 둘러보기 | 지역을 선택하면 해당 지역에 공개 저장이 있는 사람과 지도만 보여준다. |
| R05 | 다른 사람 지도 | 공개 닉네임/소개/허용 장소와 공개 개수만 보여준다. 비공개 총수는 노출하지 않는다. |
| R06 | 내 지도로 재저장 | 한 사람당 같은 장소는 하나다. 출처의 개인 메모/방문 기록/공개 설명을 복제하지 않는다. |
| R07 | 국제 지역 필터 | 국가와 가변 깊이 지역을 지원한다. 하위 지역 포함, 지역 미분류, 지도 범위 검색이 구분된다. |
| R08 | 지역 공유 | 선택한 지역의 장소를 확인하고 선택해 공유한다. 공유 화면에서 허용 범위를 임의로 넓힐 수 없다. |
| R09 | 공개범위 | private / unlisted / public과 공개 지도 활성 여부를 구분한다. 기본은 private다. |
| R10 | 공유 수명 | 만료/철회/재발급, 장소 비공개 전환/삭제, 계정 정지/탈퇴를 다음 권한 검사에 반영한다. |
| R11 | 앱 없는 사람의 열람 | 공개/공유 링크는 모바일 웹에서도 지도와 목록으로 열린다. 앱 설치를 강제하지 않는다. |
| R12 | 글로벌 로그인과 계정 | Google 로그인, iOS Apple 로그인, 계정 연결/복구 안내, 로그아웃/탈퇴가 동작한다. Apple로 가입한 사용자의 Android 접근 경로도 검증한다. |
| R13 | Google 일괄 가져오기 | Takeout ZIP/CSV를 선택하고 목록/행을 미리 본 뒤 비공개로 가져온다. 중복, 미해결, 제외 건수를 보여준다. |
| R14 | Google 단일 장소 입력 | Google 장소 링크 붙여넣기와 OS 공유 수신 후 후보 확인/저장이 동작한다. 목록 전체 링크는 일괄 가져오기와 구분한다. |
| R15 | 목록 이름 보존 | 가져온 리스트 이름을 개인 폴더로 보존한다. 한 장소가 여러 폴더에 들어가도 중복 저장하지 않는다. |
| R16 | 내 데이터 내보내기 | 본인 기록의 JSON/CSV를 만들고 개인 메모 포함 여부를 안내한다. Google 재배포 제한 콘텐츠는 제외한다. |
| R17 | 오류/위치/접근성 | 위치 권한 없이 이용 가능하다. 네트워크 실패, 지도 오류, 키보드, 스크린리더에서도 핵심 흐름을 완료한다. |
| R18 | 신고/차단/운영 | 공개 설명과 사용자 신고, 차단, 운영자 숨김, 문의 경로가 실제로 작동한다. |
| R19 | 다국어/국제화 | 한국어/영어, Unicode, 지역별 표시, 시간대, 날짜변경선 지도를 검증한다. |
| R20 | 실제 스토어 출시 | TestFlight와 Play 테스트를 거쳐 심사/공개 배포까지 수행한다. 제출과 승인은 별도 상태로 기록한다. |

R14의 공유 수신은 개발 시작 시 iOS/Android 실제 빌드로 먼저 검증한다. SDK의 실험적 API를 검증 없이 릴리스의 필수 의존성으로 만들지 않는다. 실패하면 검증된 네이티브 확장 구현 또는 명시적인 범위 변경 결정을 한다. Takeout와 붙여넣기를 조용히 제거하는 방식으로 해결하지 않는다.

## 3. 화면 구조

하단 탭은 `내 지도 / 둘러보기 / 프로필` 세 개다. `+ 저장`은 공통 액션으로 제공한다. 처음부터 피드, 채팅, 예약, 결제 탭을 만들지 않는다.

| 화면 | 핵심 구성 | 상태/주의 |
|---|---|---|
| 내 지도 | 지도, 목록 bottom sheet, 국가/지역 칩, 방문 상태, 개인 폴더, + 저장 | 타인 핀이 섞이지 않는다. 미분류/좌표 확인 필요 항목을 별도로 찾을 수 있다. |
| 저장 추가 | 장소 검색 / Google에서 가져오기 / 링크 붙여넣기 | 검색어 입력 후 요청한다. 클립보드를 몰래 읽지 않는다. |
| 장소 확인 | 현재 장소명/주소/국가, 지도, 내 메모, 태그, 방문 상태, 지역 | 동명이점/이전/폐업/찾을 수 없음 구분. 확인 전 자동 저장하지 않는다. |
| 둘러보기 | 지역 선택, 사용자 검색, 공개 지도 카드 | 가짜 팔로워나 AI 취향 점수 없이 관련 지역과 최근 업데이트로 정렬한다. |
| 상대방 지도 | 작성자, 선택 지역, 공개 핀/목록, 내 지도에 저장 | `저장됨`은 방문 인증이나 추천을 뜻하지 않는다. |
| 가져오기 | 방법 안내 → 파일 → 목록 선택 → 지역 힌트 → 행 검토 → 확정 → 결과 | 처리 중 이탈/중단/재시도/취소와 미해결 행 복귀를 지원한다. |
| 공유 만들기 | 지역 → 장소 선택 → 외부 표시 미리보기 → 공개범위 확인 → 만료 → 링크 | 목록/폴더 이름, 개인 메모, 방문 날짜를 자동 공개하지 않는다. |
| 공유 열람 | 허용 장소 지도/목록, 작성자 표시 허용 시 닉네임, 앱 열기 | 앱이 없으면 동일 권한의 웹 화면. 만료/철회는 공통 안내. |
| 프로필/설정 | 내 공개 지도, 개인 폴더, 공유 관리, 언어, 가져오기/내보내기, 차단, 문의, 탈퇴 | 소셜 로그인 이름/사진을 공개 프로필로 자동 복제하지 않는다. |

검색은 `전 세계`와 `선택 지역 우선`을 명시적으로 구분한다. 서울에서 앱을 켰다는 이유만으로 뉴욕 상호 검색을 실패시키지 않는다. 기본 지도 중심은 마지막 선택 지역, 없으면 사용자가 고른 지역이다. 첫 실행에 정밀 위치 권한을 요구하지 않는다.

## 4. 저장 모델의 사용자 의미

`장소`는 특정 음식점 지점이다. `저장`은 사용자가 그 장소를 담은 기록이다. `개인 폴더`는 자기 저장을 묶는 분류다. 폴더 삭제는 저장 삭제가 아니다.

기본값은 `want`, `is_recommended=false`, `private`. `visited`는 본인이 표시한 방문 기록이지 검증 배지가 아니다. 추천은 visited일 때만 켤 수 있다. 가져온 Google 별표/즐겨찾기를 visited나 별점으로 추정하지 않는다.

개인 메모, 태그, 방문 날짜, 가져온 원문, 원본 URL, 개인 폴더명은 항상 소유자 전용이다. 공개 설명은 별도 plain text 필드이며 280자 이하다. 공개 방문 상태는 별도 선택에 동의한 경우만 표시하며 P0 기본은 표시하지 않는다.

다른 사람 지도의 장소를 저장하면 내 기록은 private/want로 생성된다. 그 장소에 대한 독립적인 내 기록이므로 원작자가 나중에 공유를 철회해도 내 저장은 삭제하지 않는다. 다만 접근 불가해진 원작자 정보와 출처 링크는 숨긴다.

## 5. 공개범위와 지역 공유

| 저장 공개범위 | 내 지도 | 둘러보기/공개 지도 | 선택된 활성 공유 링크 |
|---|---:|---:|---:|
| private | 보임 | 안 보임 | 안 보임 |
| unlisted | 보임 | 안 보임 | 보임 |
| public | 보임 | 공개 지도 활성 시 보임 | 보임 |

공개 지도 비활성은 공개 검색 노출만 끈다. 별도 생성한 링크까지 자동 철회하는 것으로 설명하지 않는다. `모든 외부 공개 중단` 액션은 공개 지도 중단과 링크 일괄 철회를 함께 수행한다.

지역 공유는 지역 필터에 해당하는 **선택 시점의 저장 ID 집합**이다. 새 저장은 자동 추가하지 않는다. private 항목을 포함하려면 해당 항목을 unlisted로 바꾼다는 확인을 받고, 서버 트랜잭션에서 변경과 공유 생성을 함께 처리한다. 내보내기/가져오기에는 이 확인을 대체하는 동작이 없다.

비공개 전환/삭제한 항목은 기존 링크 항목도 제거한다. 다시 public으로 바꿔도 옛 링크에 되살아나지 않는다. 지역 수정으로 공유 지역 밖으로 나간 항목은 해당 공유에서 제거하고, 다시 돌아와도 자동 재추가하지 않는다. 추가/재공유는 별도 미리보기를 거친다.

링크는 재전달 가능한 열람 권한이다. `친구만`이라고 부르지 않는다. 이미 본 화면, 스크린샷, 상대방의 독립 저장까지 회수할 수 있다고 약속하지 않는다. 앱 백그라운드 복귀와 수동 갱신 때 권한을 재검사한다.

## 6. 국제 지역 UX

```text
대한민국 → 서울 → 성동구 → 성수동
미국 → New York → New York City → Manhattan
일본 → 東京都 → 渋谷区
```

위는 UI 예시다. 국가별 정확한 분류는 독립된 지역 카탈로그를 따른다. 이름 문자열을 DB 키로 쓰지 않는다. 누락된 단계는 건너뛰고 동일 이름 지역은 국가/상위 지역으로 구분한다. 인기 생활권은 공식 행정구역과 다른 선택 항목이다.

사용자에게 지역 분류가 없는 장소를 숨기지 않는다. `지역 미분류`에서 한번에 선택/지정할 수 있게 한다. 주소가 불완전하면 임의 국가나 좌표를 확정하지 않는다. 지역 필터와 지도 화면 범위는 별도 조건으로 표시한다.

## 7. 첫 출시에서 하지 않는 것

P1: 사람 팔로우, 공개 컬렉션 구독, 공동 편집, 사용자 사진 업로드, 푸시 알림, 지원 국가의 승인된 Data Portability API 연결, 확장된 파일 포맷.

P2: AI 취향 추천, 댓글/DM/피드, 결제/구독/광고/예약 수수료, 백그라운드 위치 추적, 오프라인 Google 지도, 리뷰 수집, Google 저장목록 쓰기/양방향 동기화.

개인 폴더는 가져온 리스트 보존 때문에 P0로 올렸다. Google 계정 연결 가져오기는 잊은 기능이 아니라 지역/심사 제약이 있는 P1이며, 첫 출시의 일괄 가져오기는 Takeout로 반드시 제공한다.

## 8. 검증할 제품 가설

처음에는 개인 지도와 가져오기만으로도 쓸 이유가 있는지 본다. 다음으로 공유를 받은 사람이 실제 장소를 보고 자기 지도에 저장하는지 확인한다. 가입 수만으로 사업 성공을 판단하지 않는다.

초기 사용성 과제는 `Google 목록 20곳 가져오기 → 지역별 5곳 공유 → 비회원 열람 → 앱 사용자 재저장`이다. 각 단계의 시간, 오류, 중도 포기 이유를 기록한다. 평생 무료/유료 가격은 아직 정하지 않는다. 외부 API 비용을 확인하기 전 무제한 이용을 약속하지 않는다.
